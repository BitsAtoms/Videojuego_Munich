# Videojuego_Munich
Videojuego a partir de reconocimiento zapatilla marca Munich

Detección con cámara Logitech y analizaremos los frames con un Script, para detectar el patrón de Munich. 

Utilizamos la libreria OpenCV de python para analizar los frames, no es necesario descargar ninguna app. Abrimos la aplicacion de camara de Windows y mediante comandos de python, cogemos los frames (foto del video) para buscar el patron.
La primera prueba es con una X de 10 x 10cm
